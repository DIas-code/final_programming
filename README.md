# Kazakhstan Legislation Analytics

Final project for **Programming for Data Analysis and Database** (ADA, Big Data Analysis master's program, AITU).

**Topic 21 — Kazakhstan Legislation Analytics** (Cluster 4).
**Author:** Dias Yermekov, ADA-2603.
**Dataset:** [KazakhLawCorpus-clean](https://huggingface.co/datasets/Arailym-tleubayeva/KazakhLawCorpus-clean) — 215,889 Kazakh legal acts (1947-10-30 … 2026-07-20), 25 metadata fields, single CSV `data/kazakhlawcorpus_kk_only.csv` (336.8 MB), CC BY 4.0.

## Goal
Analyze dynamics of legal acts by year, act form, adopting body, region, and repeal status; normalized SQLite schema; EDA + time series + Streamlit dashboard; naive / seasonal-naive / moving-average / linear-regression forecast comparison (MAE).

## Stack
Python 3.14, Pandas 3.1, PyArrow, SQLite (stdlib `sqlite3`), Matplotlib/Seaborn, Plotly, Streamlit, statsmodels, scikit-learn.
Developed and tested on Windows 11 (PowerShell). Exact versions are pinned in `requirements.txt`.

## Run (Windows, PowerShell)

```powershell
py -3.14 -m venv .venv
.venv\Scripts\Activate.ps1          # if blocked: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
python -m pip install --upgrade pip
pip install -r requirements.txt

# 1. Download CSV (~337 MB) -> data/raw/, chunked read, dtype optimization, Parquet + benchmarks
python -m src.data_loader
# 2. Metadata audit -> docs/audit.md
python -m src.audit
# 3. Normalize + load into SQLite -> data/legislation.db
python -m src.db
# 4. SQL analytics, EDA, time series, forecast -> docs/figures/, docs/results/
python -m src.queries
python -m src.analysis
python -m src.forecast

# 5. Dashboard
streamlit run src/app.py
```

macOS / Linux: `python3 -m venv .venv && source .venv/bin/activate`, the rest is the same.

## Structure

```
src/
  config.py        paths and constants (pathlib, works on Windows/macOS)
  data_loader.py   download, chunked CSV -> Parquet, dtype optimization, benchmarks
  audit.py         metadata audit (missing, dates, multi-value fields, placeholders)
  db.py            normalized schema, load to SQLite
  queries.py       10 SQL queries (JOIN, GROUP BY/HAVING, CTE, window functions)
  analysis.py      EDA + correlations + time series + figures
  forecast.py      naive / seasonal naive / moving average / LinearRegression, MAE
  app.py           Streamlit dashboard with filters
data/              raw CSV, Parquet, SQLite db (gitignored, regenerated by the scripts)
docs/              audit, ER diagram, figures, results, report, presentation
```
